## Why it matters

The repository can point to the paper while the paper still leaves readers unable to
find the exact code and data release used for the results. Both directions are needed.

## How to satisfy it

Add a data and code availability statement to the manuscript that links to the archived
release and cites its DOI according to the journal's guidance.
